# Changelog

## v0.1.0 — Developer Preview · 2026-10-25

- Added six-category privacy detector with Luhn checks for payment-card candidates and conservative overlap suppression.
- Added category-specific block/redact/monitor policy persistence and safe defaults.
- Added local protected text chat gateway with input and output inspection and strict loopback-only upstream allowlist.
- Added authenticated local controller with random session token, Origin/Host checks, response security headers, no cross-site CORS and bounded JSON bodies.
- Added metadata-only SQLite audit, event retention and professional PDF evidence report.
- Added OpenSSH alias discovery, strict fingerprint validation, read-only host queries and private localhost SSH tunnels.
- Added responsive dark user interface with policy editor, scanner, gateway setup, connections, audit and reports.
- Added source packaging self-test, Windows installer, macOS DMG and Linux DEB recipes with prerelease GitHub Actions publishing.
- Added animated README visuals, architecture, security model, tests, installation and complete handover docs.

**Known release gates:** unsigned/unnotarized binaries, real-device tests, external penetration testing, sensitive-data detector quality evaluation, enterprise authentication/authorization and model-specific end-to-end testing.
