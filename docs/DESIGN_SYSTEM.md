# SparkPrivacy visual language

**Identity:** modern professional enterprise security console. Deep navy (`#091321`), layered slate cards (`#122333` / `#152536`), mint/jade (`#61e4c1`), subtle blue (`#87aefb`), red/amber only for risk/warnings. System UI fonts; no externally hosted assets, font files or telemetry.

## App interface

Left navigation on desktop and collapsible drawer on mobile. Honest numerical cards derived from local audit, empty states when history is empty, clearly named controls and safe sample data. Inputs have labels and keyboard focus indicators. Use no fake success banners or fabricated threat/benchmark statistics.

## Documentation visuals

- `docs/sparkprivacy-hero.svg`: editorial product banner, gentle shield-orbit motion.
- `docs/sparkprivacy-workflow.svg`: animated pipeline of inspect, decide, forward, inspect output, log.
- `docs/sparkprivacy-console.svg`: animated **illustration**, not an actual screenshot or live telemetry.
- `docs/sparkprivacy-architecture.svg`: implemented system and security boundary, subtle animated connectors.

All SVGs include `title`/`desc`, reduced-motion media rules and self-hosted vector content. Motion must be tasteful and informative; do not use UI animation as evidence of a real connected Spark or passed test. Real screenshots should be captured from verified builds and timestamped.
